# Документация котельной — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Комплект документации котельной под замену котла на настенный одноконтурный ~28 кВт (открытая камера,
OpenTherm, Wi‑Fi) в `docs/boiler-room/`: схемы обвязки (A — ГОСТ, B — цветная), спецификация, расчёты, выбор котла,
дымоход/вентиляция/газ, схемы подключений, порядок замены.

**Architecture:** Markdown-документы + SVG-схемы, написанные вручную (общие условные обозначения в `<defs>` каждого
файла). Единый реестр позиций — таблица спецификации; схемы ссылаются на позиции атрибутами `data-pos` /
`data-ref`. Скрипт `check_docs.py` сверяет схемы, спецификацию и `PINOUT.md`; `calc.py` воспроизводит расчёты.

**Tech Stack:** Markdown, SVG 1.1, Python 3 (stdlib) для проверки и расчётов, Playwright (уже есть) для рендера SVG в PNG.

**Spec:** `docs/superpowers/specs/2026-10-17-boiler-room-docs-design.md`

## Global Constraints

- Язык — русский; термины как в проекте (БКН, ПЗА, гидрострелка, подпитка).
- Неизвестное — «уточнить», допущение — «допущение»; никаких выдуманных марок как «существующих».
- Позиции: гидравлика — целые числа `1…` сквозные; электрика — коды ГОСТ 2.710 (`A1` ESP32, `A2` модуль реле,
  `A3` OT-адаптер, `A4` RF-шлюз, `G1` БП 5 В, `BK1…BK10` DS18B20, `BK11` DHT22, `BP1` давление отопления, `BP2`
  давление воды, `M1…` насосы, `YA…` приводы клапанов/кранов, `EK1` ТЭН, `KM1` контактор ТЭНа, `HL1/HL2` лампы,
  `HA1` зуммер, `QF…` автоматы, `XT…` клеммники). Гидравлическая позиция с электрикой несёт оба (`поз. 14 / M2`).
- Шифры трубопроводов (ГОСТ 21.206): Т1 подача отопления, Т2 обратка, В1 холодная вода, Т3 ГВС, Т4 рециркуляция,
  подпитка — В1 (отдельной ветвью), газ — Г1.
- Каналы реле и GPIO — строго как `firmware/esp32-homesite/PINOUT.md`; OT: вход GPIO36, выход GPIO5 (реле 15
  освобождается), реле котла (канал 0) — аппаратное отключение котла.
- Датчики температуры подписываются именами из БД: `tsboiler_s/b`, `tsrad_s/b`, `tsfloor_s/b`, `tsihb_s/b`,
  `tswatersupply_c`, `tswatersupply_h` (гильза в верхней части бака); давление `prs_heating` — на трубе подпитки
  под гидрострелкой, `prs_water` — на магистрали сразу после насоса скважины.
- Исходные: дом 200 м², тёплый пол ≈ 80 м², 15 радиаторов × ~8 секций, БКН 200 л / змеевик 30 кВт, трубы —
  нержавейка пресс V-профиль, патрубки котла 3/4", газ магистральный, дымоход вертикальный есть, внешний
  расширительный бак + группа безопасности дополнительно к встроенным в котёл.

## Review Focus

- Позиция есть на схеме, но нет в спецификации (или наоборот) → `check_docs.py` падает (Task 1).
- Канал реле / GPIO в схеме подключений не совпадает с `PINOUT.md` → `check_docs.py` падает (Task 1, данные Task 7).
- SVG не открывается (битый XML) или текст обрезан при рендере → XML-проверка в `check_docs.py` + PNG-рендер и
  просмотр каждой схемы (Tasks 3, 4, 7).
- Диаметр/объём в спецификации не совпадает с расчётом → значения в спецификации берутся из вывода `calc.py`,
  `check_docs.py` сверяет ключевые (Task 2).
- Тёплый пол получает воду выше допустимой при отказе смесителя → в схеме и спецификации есть защита
  (накладной термостат 50–55 °C, отключающий насос пола) или явная пометка, почему её нет (Task 3).

### Task 2: Расчёты

**Files:** Create `docs/boiler-room/calc.py`, `docs/boiler-room/04-calculations.md`

**Interfaces — Produces:** `calc.py --json` → словарь с ключами `heat_load_kw`, `flow_<контур>_m3h`, `dn_<участок>`,
`exp_heating_l`, `exp_dhw_l`, `system_volume_l`, `coil_check`.

- [ ] Укрупнённая теплопотеря (Вт/м², допущение указать) и сверка с котлом 28 кВт.
- [ ] Расходы G = Q / (c·ΔT) по контурам: котловой, радиаторы (ΔT 15–20), пол (ΔT 5–8), загрузка БКН (30 кВт).
- [ ] Диаметры нержавейки (ряд наружных диаметров пресс-систем 15/18/22/28/35 мм) по скорости 0,4–0,8 м/с
  магистрали, ≤ 1,0 м/с коллектор/котловой; патрубки котла 3/4" — переход.
- [ ] Объём системы (котёл, радиаторы ~ л/секцию, пол ~ л/м по шагу, трубы, БКН-змеевик, гидрострелка) и
  расширительный бак по формуле `V = Vсист·e / (1 − (P0+1)/(Pmax+1))`, минус встроенный бак котла; бак ГВС
  для БКН 200 л; давление преднастройки.
- [ ] Проверка насосов (напор/расход) — требования к насосам для спецификации; змеевик 30 кВт vs котёл 28 кВт —
  время загрузки бака.
- [ ] `04-calculations.md` — исходные, допущения, формулы, таблицы результатов (числа из `calc.py`).
