# 3. Спецификация оборудования, изделий и материалов

Форма — по ГОСТ 21.110 + колонка **Статус**: **есть** — стоит сейчас и остаётся; **купить** — новое;
**уточнить** — есть, но модель/параметры неизвестны (проверить на месте). Марки с пометкой «пример» — один из
подходящих вариантов, выбор за владельцем по требованиям в колонке «Наименование». Диаметры и объёмы — из
`calc.py` (раздел 4). Ред. 2 — по ревью сантехника (практика kotelna.tk). Позиции совпадают со схемами: лист 1 (`01-overview.svg`), лист 2 (`02-piping.svg`),
листы 3–8 (`07a…07f`). Трубы — нержавеющая сталь, пресс-фитинги с V-профилем (наружный диаметр × стенка).
