# Котельная — документация под замену котла

Замена двухконтурного Beretta City 28 CSI (закрытая камера) на **настенный одноконтурный котёл ~28 кВт с открытой
камерой, OpenTherm и Wi‑Fi**. ГВС — бойлер косвенного нагрева 200 л от гидрострелки; управление котлом — контроллер
HomeSite по OpenTherm, Wi‑Fi производителя — только просмотр.

## Как читать

- **Позиция** — число на полке выноски (лист 1–2) и в первой колонке спецификации; **обозначение** (A1, M2, BK3, YA1…)
  — код по ГОСТ 2.710 на схемах подключений. У гидравлики с электрикой оба: поз. 7 / M2.
- **Датчики** подписаны именами из базы HomeSite (`tsboiler_s`, `prs_heating`…) — те же, что на странице «Схема».
- **Статусы**: «есть» — стоит и остаётся; «купить» — новое; «уточнить» — проверить на месте.
- **ДОПУЩЕНИЕ** в расчётах — значение без замера; при уточнении поменять в `calc.py` и пересчитать.

## Главные допущения

- Теплопотери 100 Вт/м² (дом 200 м² → 20 кВт); тёплый пол 60 Вт/м² на 80 м².
- Объём системы ~190 л (секции 0,35 л, пол — труба 16×2 шаг 150 мм, разводка 40 л).
- Порог реле давления скважины ~3 бар (по датчику `prs_water`).
- Встроенный расширительный бак котла ~8 л — не учитывается, внешний бак 24 л покрывает систему один.
- Модели насосов и клапанов не известны — требования по расчёту, стоящие проверить на соответствие.

## Инструменты

```bash
python3 docs/boiler-room/calc.py           # пересчитать (после правки допущений)
python3 docs/boiler-room/draw_piping.py    # перерисовать листы 1–2
python3 docs/boiler-room/draw_wiring.py    # перерисовать листы 3–5
python3 docs/boiler-room/check_docs.py     # сверка: позиции схем ↔ спецификация, реле ↔ PINOUT.md, числа расчёта
python3 -m pytest docs/boiler-room -q      # тесты инструментов
```

Схемы — SVG, генерируются скриптами (правки — в скриптах, не в SVG). Открываются в браузере и на GitHub,
печатаются из браузера (альбомная, «по размеру страницы»).
