# esp32-rf-gateway — прошивка RF-шлюза

ESP32 DevKit + CC1101 433,92 МГц. Принимает беспроводные датчики (rtl_433_ESP) и публикует их в MQTT. Выводы —
[`PINOUT.md`](PINOUT.md), схема — `docs/boiler-room`, лист 6.

## Сборка и прошивка

```bash
cd firmware/esp32-rf-gateway
pio run                    # сборка (раздел huge_app: декодеры rtl_433 не влезают в обычный)
pio run -t upload          # прошивка по USB
pio device monitor         # лог, 115200
```

Не входит в режим прошивки — зажать BOOT, нажать EN, отпустить BOOT. Настройки в NVS переживают перепрошивку.

## Первая настройка

1. Без настроек плата поднимает точку доступа **`RFGW-setup`**.
2. Подключиться, открыть **http://192.168.4.1**.
3. Заполнить: Wi‑Fi, MQTT-брокер (`192.168.55.10:1883`), имя шлюза, часовой пояс. Сохранить.

Сброс настроек: **BOOT 5 с** в работе или зажать BOOT при включении.

## Особенности

- **Датчики привязываются с сервера:** `scan_sensors` показывает всё, что слышно (модель, id, канал, RSSI); имя
  (`clm_*`) задаётся в админке. Неизвестный протокол — включить `raw_debug` (команда с сервера) и смотреть сырые пакеты в `…/rf_debug`.
- **CC1101 — только 3,3 В**, развязка 100 нФ + 10 мкФ у модуля, SPI-провода короткие.
- Шлюз ставить вне металлического щита, антенна ¼λ 17,3 см вертикально.
- Библиотека rtl_433_ESP закреплена на коммите в `platformio.ini` (у неё менялся API без смены версии). OTA нет.
