# esp32-homesite — прошивка контроллера котельной

ESP32-DevKitC (**WROOM-32**, не WROVER). Реле, датчики, защиты котла, MQTT. Выводы — [`PINOUT.md`](PINOUT.md),
схема — `docs/boiler-room`, листы 7–8 и раздел 7.8 `07-wiring.md`.

## Один раз до монтажа

```bash
pip install esptool
espefuse.py --port COMx set_flash_voltage 3.3V     # GPIO12 (реле K1) — загрузочный вывод
```

Без этого модуль реле может подтянуть GPIO12 при сбросе → flash 1,8 В → плата не загрузится. Запись eFuse
**необратима**, делается один раз на плату.

## Сборка и прошивка

```bash
cd firmware/esp32-homesite
pio run                    # сборка
pio run -t upload          # прошивка по USB (порт находится сам; иначе --upload-port COMx)
pio device monitor         # лог, 115200
```

- **Перед прошивкой по USB снять +5 В от БП G1** (клеммник X1): USB и внешние 5 В одновременно нельзя.
- Не входит в режим прошивки — зажать BOOT, нажать EN, отпустить BOOT.
- Настройки (Wi‑Fi, MQTT, датчики) хранятся в NVS и переживают перепрошивку.

## Первая настройка

1. Без настроек плата поднимает открытую точку доступа **`HomeSite-XXXX`** (XXXX — конец MAC).
2. Подключиться, открыть **http://192.168.4.1** (откроется само как captive portal).
3. Заполнить: Wi‑Fi, MQTT-брокер (`192.168.55.10:1883`, логин/пароль), имя узла (`boiler_unit`), часовой пояс,
   датчики давления, пины реле и галку **«Invert logic»** — **снята** для модулей с перемычкой H (HIGH = вкл.),
   стоит — для плат L / JD-VCC (LOW = вкл.).
4. Сохранить — плата перезагрузится и подключится к Wi‑Fi. Адреса DS18B20 — сканом в портале или командой `scan_sensors`.

Сброс настроек: **BOOT 5 с** в работе или зажать BOOT при включении → снова точка доступа.

## Особенности

- **Уставки и режимы приходят с сервера** по MQTT (`home/devices/<имя>/cmd`); после перезагрузки платы шлюз сам
  досылает все ключи. Диапазоны — таблица `SETTINGS` в `src/boiler_logic.cpp` (зеркало — `backend/app/core/setting_rules.py`).
- **Без Wi‑Fi защиты работают**: контроллер не уходит в портал после пропажи сети, а работает автономно и
  переподключается.
- **Реле инициализируются первыми** — до Wi‑Fi и портала; пары «открыть / закрыть» приводов не включаются вместе
  (пауза 500 мс), аппаратно — через NC (лист 8).
- **Обновление на старом контроллере** с модулями LOW = вкл.: после прошивки проверить галку «Invert logic» в портале —
  по умолчанию теперь HIGH = вкл.
- OTA нет — только по USB.
